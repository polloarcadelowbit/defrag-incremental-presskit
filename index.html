:: ABOUT

A defrag utility that got a bit out of hand

Defrag Incremental starts like a very simple PC utility. Pick a disk, choose how to process it and try to finish the job before the workday ends.

As progression continues, disks become larger, hotter, damaged and more valuable. Different algorithms and modes suit different jobs, temporary upgrades improve the current run, and heat, disk health and active events start getting in the way.

Rebooting starts a new run and converts accumulated Reboot Charge into BIOS Chips for permanent BIOS upgrades. Later systems include automation, expert stop rules, daily conditions, contracts, Diskdex progression and a separate life/economy layer.

Automation handles routine work, but it is deliberately not perfect. Active play is normally faster and gives the player more control.

:: CURRENT BUILD

Version 1.1

The current version was released on 4 September 2026. Its main goal was simple: make the interesting parts of the game happen earlier.

Heat and disk health now matter much sooner, and defragging can trigger active events that require a decision. The life/economy layer was rebuilt, upgrade information is clearer, and permanent BIOS progression is easier to inspect.

It also added manual saving, clearer system-stat and BIOS-purchase panels, improved window resizing and support for more aspect ratios, plus progression and UI fixes based on post-launch feedback.
